## Objective

Create a discovery script that runs the existing `CohortChartDetector` against all filings in the database, logging detected chart images with metadata to enable manual analysis.

**Business Rationale**: Before investing in image extraction infrastructure, we need to understand the scope: How many filings contain charts? What types? Do chart values duplicate text? This script produces the raw data for that analysis.

**Current Behavior**: `cohort_chart_detector.py` exists but is not integrated into a corpus-wide analysis workflow.

**Desired Behavior**: A script that scans all filings, detects chart images, and produces a structured CSV/JSON report for manual review.

## Prerequisites

- None (standalone discovery task)
- Database must contain filings with stored HTML (filings table + html_storage_path)

## Files to Create

1. **`scripts/discover_chart_images.py`** - Main discovery script
2. **`data/discovery/chart_image_inventory.csv`** - Output inventory (generated by script)

## Files to Read (Context Only)

- `src/extraction/cohort_chart_detector.py` - Existing detection logic to reuse
- `src/extraction/segment_enricher.py` - `_detect_cohort_chart_images()` for segment-level detection
- `src/infra/db.py` - Database query patterns

## Implementation Requirements

### Core Functionality

1. **Filing Enumeration**
   - Query all filings from database with html_storage_path
   - Support `--limit N` argument for testing (default: all filings)
   - Support `--filing-id ID` for single-filing analysis

2. **Chart Detection**
   - Instantiate `CohortChartDetector` and run on each filing's HTML
   - Capture all detected images (not just cohort-related)
   - Extend detection to find ALL `<img>` tags, not just those near cohort keywords

3. **Output Data Structure**
   ```
   filing_id, company_name, accession_number, image_src, image_url,
   width, height, chart_type_guess, cohort_keyword_nearby,
   preceding_text (50 chars), detection_confidence, image_count_in_filing
   ```

4. **Logging**
   - Progress: "Processing filing X of Y: {accession_number}"
   - Summary: "Found N images across M filings (avg X.X per filing)"
   - Errors: Log and continue on individual filing failures

### Error Handling

- **Missing HTML file**: Log warning, skip filing, continue
- **Invalid HTML**: Log warning, skip filing, continue
- **Database connection**: Fail fast with clear error
